微信是独立、默认关闭的文字通知通道，可与 Telegram、Discord、邮件同时使用。它有自己的语言、事件选择、CPU 和内存阈值，以及独立的定时报告计划。

企业微信模式向企业微信群机器人发送消息。个人微信需要另外部署兼容下文协议的桥接服务，并由该服务维护可用的微信连接。面板不包含这个桥接服务，也不提供直接登录个人微信机器人的入口。

## 配置

1. 打开 **面板设置 → 微信**，启用通知。
2. 选择发送方式。
   - **企业微信群机器人**：在企业微信群中添加消息推送机器人，填写其 HTTPS Webhook 地址。见[企业微信官方说明](https://developer.work.weixin.qq.com/document/path/99110)。
   - **自定义 Webhook 网关**：填写自己实现的兼容 HTTPS 接口，按需配置接收端校验的 Bearer Token，再由该服务向个人微信投递。接口必须实现下文协议，微信联系人或任意第三方推送 URL 不能直接作为接收端。
3. 选择通知语言，该设置独立于 Telegram 机器人语言。
4. 在 **通知** 中选择事件和指标阈值。阈值为 `0` 时关闭对应指标告警。
5. 按需启用定时报告并设置计划。`@daily` 使用面板调度器的时区。
6. 先 **保存**，再 **发送测试通知**。测试使用已保存的配置；通道关闭或存在未保存的设置修改时，测试按钮不可用。

地址可能包含机器人密钥，因此地址和 Token 均在返回浏览器时隐藏。留空保留原值，点击 **清空** 后保存才会删除。清除必填地址前应先关闭通知。保存后会更新报告计划和指标采样任务，无需重启面板。

## 内容和频率

可选事件包括登录尝试、CPU 和内存超阈值、Xray 崩溃、节点离线与恢复、出站不可达与恢复。默认选择登录尝试和 CPU 告警。登录通知包含尝试的用户名、来源 IP、结果和可用的失败原因，不包含密码。

同类事件和来源每分钟最多成功发送一次；同一来源的登录失败和成功分别限频。发送失败不占用成功发送的冷却时间。

报告汇总主机、面板和 Xray 版本、CPU、内存、磁盘、运行时间，以及入站和客户端的总数、禁用、过期、流量耗尽数量。Xray 停止时仍能报告状态。此通道不提供远程命令或文件备份，报告不包含订阅链接和客户端配置文件。

流量只汇总本面板管理的客户端统计，按客户端邮箱去重。已用流量为上传与下载之和；剩余流量为每个客户端额度扣除已用量后的非负余额之和，运行统计中未设置额度时回退到客户端配置的额度。没有客户端统计，或任意客户端未配置额度时，剩余流量显示 **未配置额度**。这不是 VPS 服务商的计费额度，也不包含绕过 3x-ui 的流量。

## 自定义网关协议

HTTPS `POST`，`Content-Type: application/json`。配置 Token 时发送 `Authorization: Bearer <token>`。

```json
{
  "version": 1,
  "id": "8f793626-a0e0-4a28-bddf-84c077a1bd21",
  "type": "event",
  "event": "cpu.high",
  "hostname": "my-server",
  "occurred_at": "2026-11-04T12:00:00Z",
  "text": "3x-ui · my-server\nCPU 使用率：92.00%；阈值：80%"
}
```

`type` 为 `event`、`report` 或 `test`。事件键为 `login.attempt`、`cpu.high`、`memory.high`、`xray.crash`、`node.down`、`node.up`、`outbound.down`、`outbound.up`；报告和测试分别使用 `report`、`test`。`occurred_at` 保留事件发生的 UTC 时间，缺失时才使用发送时间。正文最多 20,480 个 UTF-8 字节。

接收端应校验认证和版本，以 `id` 为唯一键可靠入队，再返回 `2xx`。这代表网关接受投递责任，最终微信消息的发送及重试由网关负责。

连接失败或 `5xx` 时，面板最多重试一次，沿用相同 ID 和正文；其他失败响应不重试。接收端应按 ID 去重，避免响应丢失造成重复消息。每次请求超时 10 秒，响应最多 4 KiB，不跟随重定向。协议不依赖特定的网关服务。

企业微信模式只接受官方机器人 HTTPS 地址，并要求响应 `errcode: 0`。长消息按 UTF-8 字节边界拆分，每段最多 2,048 字节、最多十段，发送间隔至少 3.1 秒。该接口不能按本通道的 ID 去重，因此不自动重试。

两种方式均直接通过 HTTPS 连接、校验证书，不继承面板出站代理。自定义地址必须指向公网，实际连接时再次阻止回环、私网、链路本地和元数据服务地址。微信适配器位于内网时，应提供公开的 HTTPS 接收网关。
