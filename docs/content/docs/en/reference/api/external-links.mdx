title: External Links
description: The panel-wide library of external links and external
  subscriptions, plus the targets each entry is assigned to. All endpoints under
  /panel/api/links. A client receives the union of the entries assigned to it
  directly, to its group, to the inbounds it sits on and to the panel as a
  whole; the most specific scope wins for overrides, and the library row itself
  is shared so one edit reaches every client that inherits it. Subscription
  entries are fetched by the panel, revalidated conditionally and never allowed
  to empty a client subscription when the provider is down.
